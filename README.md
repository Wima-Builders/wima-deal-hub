---

## To make the website download links work

The download section on `index.html` links to these files **by filename at the site root**. Upload all six PDFs to your GitHub repository in the **same folder as `index.html`** — not in a subfolder.

Once uploaded, they'll be live at addresses like:
`https://wimabuilders.com/Wima_Catalogue_All_Categories.pdf`

**Keep the filenames exactly as they are.** Renaming any file will break its download link on the site.
